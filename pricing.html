How RCTV Connections Work

RCTV pricing is based on the number of simultaneous connections you need. A connection represents how many devices can be watching RCTV at the same time, not how many devices you can install RCTV on.

Example: If you have 3 Fire Sticks but only plan to watch RCTV on one device at a time, you only need a 1 Connection plan. You can enter your RCTV username and password on all three devices, but only one can stream at any given time.
If you have 2 Fire Sticks and want both of them to stream RCTV at the same time, you will need a 2 Connections plan. The same principle applies if you need 3, 4, or 5 devices streaming simultaneously.

What Counts as a Device?

The type of device doesn't matter. A connection can be used on any compatible device, including:

Fire Stick • Phone • Android Box • Tablet • Laptop

What matters is simply how many devices are using RCTV at the same time.

Planning Ahead Can Save You Money

If you think you'll need more than one simultaneous connection, we recommend choosing the appropriate number of connections when starting your subscription.

Upgrading the number of connections during an active subscription may cost more than selecting the additional connections from the beginning.
